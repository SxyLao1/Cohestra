# Recipient Examples

These files demonstrate Cohestra's public contracts without selecting a
provider, desktop application, home directory, database, or credential source.

- `registry.json` declares two neutral Agent roles and their Skill exposure modes.
- `shared-guide.md` shows the eight-section selective-loading contract.
- `adapter.py` dispatches one in-process request through an explicitly registered example adapter.

Copy the shapes into a recipient-owned private overlay and replace identifiers
and paths there. Do not add that private overlay to the Cohestra repository.
