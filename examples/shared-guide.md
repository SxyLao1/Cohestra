# Shared Agent Guide

## 1. Communication

Lead with the observed result, evidence boundary, impact, and next action.

## 2. Deliverables

Keep source evidence distinct from derived reports and generated artifacts.

## 3. Code Rationale

Document non-obvious safety, compatibility, concurrency, and lifecycle reasons.

## 4. Progress

Report meaningful phase changes, validation results, and blockers.

## 5. Files And Tools

Use declared project roots and verify tools before relying on them.

## 6. Coordination

Assign one writer per file and treat memory or worklogs as routing evidence.

## 7. Decisions

Resolve unclear, costly, or externally visible choices before irreversible work.

## 8. Governance

Review and validate shared-rule changes before distributing them.
